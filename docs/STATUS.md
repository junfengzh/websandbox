## Known limitations

Collected from docs/NOTES-*.md:
- **Grading.** Fuzzy answers (78 WebArena tasks, e.g. the "N/A" ones) need the RL stack's LLM judge.
  `must_include` on numbers accepts any equal number in the answer, but count/amount questions are
  graded with strict numbers (kit/README.md "Grading"): any other number not in the intent fails, so
  listing numbers no longer guesses a count -- and an extra legit number ("3 orders, total $45") fails
  too; non-count numeric questions (ids, zip codes, prices asked as "what is") still accept extra
  numbers; order-sensitive pairs are asked one value per task. Vote tasks do not penalise extra votes on
  other posts (as WebArena). Map "nearest" is straight-line distance (what the UI lists).
- **Store.** Search relevance is untuned against Magento; Reorder adds separate cart rows; no rating sort;
  complete orders have no `total_paid`; listing ratings are only in an aria-label; few invoices/shipments in the
  source data.
- **Forum.** The clock (2023-07-11) is past the data (ends 2023-03-31), so time-window sorts are empty;
  nobody moderates a forum in the data (moderation tasks use the admin); downloaded images re-uploaded
  do not match the original (re-encoded WebP).
- **Code.** Open MRs whose merge base is outside a truncated import's history (13 on gcc-mirror/gcc) or too large to
  check (processwire!247's line-ending rewrite) show a "Merge blocked" reason instead of a merge button (fixed from
  HTTP 500 / minutes; every MR and issue page now renders, p95 <= 26 ms, docs/NOTES-code.md). Imported issues/MRs are authored by root ("Created by" in the body); `closed_at`/`merged_at` are NULL
  for imported rows; profile website shows its scheme; README pages with external images never fire `load`
  offline (harnesses should not wait for `load` or should block external requests).
- **Wiki.** No categories / talk pages / history; full-text search ranks question-style queries weakly (the Go
  box and autocomplete find titles); suggestions can favour navbox-inflated pages.
- **Map.** Only the US Northeast extract has tiles/routing for WebArena (Mackinac Bridge is geocoded only);
  some searches miss as on Nominatim ("Upitt", "PIT airport", bare "Whole Foods"); chain names follow the view;
  turn penalties do not steer routing; in-place map navigation needs WebGL (headless `--disable-gpu` has none).
- **Store admin.** Categories / Customer Groups are plain multi-selects (Ctrl-click); the Reviews grid has no product filter.
- **Cross-site.** Cookies are per host: cross-site runs need `--bind rl` (own address per site).
